<h1>
  EduLibrary
</h1>

An simple educational library for students! 📚

You can: 
- Upload eBooks
- Download eBooks
- Find books by Name, Author and Year
- Create an account
- Reserve a book

# Build Tools
- PHP
- HTML
- Bootstrap 5
